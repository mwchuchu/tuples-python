#  Music Genres Tuple - Jupyter Notebook

A simple Jupyter Notebook exploring Python tuple data structures using a music genres dataset with nested sub-genres.

##  Overview

This notebook demonstrates the use of Python **tuples**, including **nested tuples**, through a curated list of music genres and their sub-genres. It serves as a beginner-friendly example for understanding:

- Tuple creation
- Accessing tuple elements
- Working with nested tuples
- Indexing and slicing

## Contents

The `genres_tuple` variable contains:

| Level | Data |
|-------|------|
| **Top-level genres** | Pop, Rock, Soul, R&B, Progressive Rock, Disco |
| **Rock sub-genres** | Hard Rock, Soft Rock |
| **Disco language variants** | English, Spanish, Iceland |

##  Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook or JupyterLab

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/mwchuchu/tuples-python.git
   cd tuples-python
   ```

2. Install Jupyter (if not already installed):
   ```bash
   pip install jupyter
   ```

3. Launch the notebook:
   ```bash
   jupyter notebook PY0101EN-2-1-Tuples.ipynb
   ```
